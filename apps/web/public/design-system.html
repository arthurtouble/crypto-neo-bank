01 · Principles

Earn trust in the details

Every screen should make ownership, risk, status, and the next action obvious. If an interface needs instructions, improve the interface before adding copy.

Information before ornament

Use hierarchy, alignment, and space to clarify the decision.

One primary action

Make the safe next step easy to find without making everything loud.

No generic card mosaics

Use a container only when it groups, contains, or enables something.

No promotional ambiguity

Never make planned, projected, or provider-gated features look live.

07 · Content

Let the interface speak

Use sentence case. Put important words first. Add help text only when a user needs it to decide or avoid harm.

Do

“Review transfer” · “Wrong address” · “Available: 28,450 USDC”

Do not

“Please click below to continue” · “Unlock your financial future” · “Seamlessly supercharge”

08 · Motion

Explain change, then stop

120–160 ms for controls, 180–220 ms for dialogs. No looping decoration. Respect reduced motion. Never delay a financial confirmation for animation.

Entry: cubic-bezier(.2,.8,.2,1) · Exit: ease-in · Movement: ≤ 8 px
