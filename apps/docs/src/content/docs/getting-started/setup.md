## 1. Sign in

Choose **Open Aurel** and use a sign-in method offered by Privy. Aurel verifies the session before showing account data.

Use an account you control for the long term. Review the recovery methods Privy presents and add a passkey when available. Aurel support cannot bypass Privy's recovery process or recreate a lost wallet secret.

## 2. Choose a wallet

You can create an embedded wallet or connect a supported external EVM wallet. The wallet, not Aurel, holds the signing authority.

An embedded wallet gives the most integrated experience. An external wallet keeps the existing wallet interface and can expose activity performed outside Aurel. Choose based on how you plan to recover and use the wallet, not on the appearance of the connection screen.

## 3. Check the network

Base mainnet is Aurel’s home network. It uses real ETH for gas and real assets. Aurel does not use Sepolia or a simulated network in the customer product.

Base addresses use the same format as other EVM networks. The same-looking address does not make assets on different chains interchangeable. Check the network at the sending service before making a deposit.

## 4. Review Safety

Before moving value:

- add a passkey to help protect account access;
- save trusted destination addresses;
- choose a review threshold;
- keep the 24-hour address cooling period enabled; and
- learn where the account lock applies.

The Aurel account lock stops Aurel from preparing new outgoing actions. It cannot stop a transaction signed in another app or from an exported wallet.

## 5. Understand the first deposit

Before depositing, confirm the asset contract and network. Aurel currently presents native ETH, native USDC, and WETH on Base. An unsupported token may reach the wallet without appearing in the portfolio.

Keep enough ETH on Base for gas. A USDC balance does not pay Base gas by itself.

## 6. Start small

Confirm the asset, network, address, and fees with a small transaction before moving a larger amount.

After the transfer, compare the sending-platform record, Base block explorer, wallet address, and Aurel activity. Do not repeat a transfer solely because one interface updates slowly.

## 7. Learn the signing flow

Aurel first prepares and checks an action. The wallet then displays the final transaction request. Read the wallet request before approving it, especially the network, recipient or contract, token approval, and amount.

If anything differs from what you intended, cancel. A support agent will never ask you to “verify” an account by signing an unexplained transaction.

## What setup does not include

Creating an Aurel wallet does not create a bank account, complete future card KYC, activate insurance, or qualify the customer for tokenized securities. Those services remain separate and will have their own provider terms and eligibility if launched.
