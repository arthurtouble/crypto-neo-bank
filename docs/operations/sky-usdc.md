# Sky USDC savings on Ethereum

The Earn card uses Spark's deployed [PSMVariant1Actions USDS wrapper](https://github.com/sparkdotfi/spark-user-actions#deployments) at `0xd0A61F2963622e992e6534bde4D52fd0a89F39E0`. Its `swapAndDeposit` call transfers Ethereum USDC, converts through the [USDS PSM](https://github.com/sparkdotfi/spark-user-actions/blob/master/src/PSMVariant1Actions.sol), and deposits USDS into Sky sUSDS for the customer's own wallet. `withdrawAndSwap` reverses this into Ethereum USDC. There is no separate customer USDC-to-USDS swap.

The server verifies the wrapper's live `gem`, `dai`, `savingsToken`, and `psm` addresses before preparing exact calls. It reads the linked wallet's USDC and sUSDS balances and previews sUSDS shares needed for withdrawal. Calls bind the recipient to the linked wallet, approve only the current amount, and cap conversion loss or fees at 1% from USDC par. The user signs each call through Privy. Ethereum contracts and receipts, rather than Aura records, decide the outcome. The card shows no APY promise.

Users need Ethereum USDC and Ethereum gas. Base USDC can be bridged separately through LI.FI/Across, then deposited after destination settlement. Aura's governed Swap path now accepts exact Base USDC → Ethereum USDC Across V4 calls with the same reviewed source, allowance, prepared-call, and destination evidence as its Arbitrum route. A current read-only LI.FI quote passed that policy. The bridge and Sky deposit are separate transactions; no funded bridge-to-Sky rehearsal has been completed. Bridge/Rain programs are unrelated to this onchain Sky flow.

Read-only mainnet inspection on 24 September 2026 confirmed the wrapper has deployed code and points to Ethereum USDC, USDS, sUSDS, and PSM `0xA188EEC8F81263234dA3622A406892F3D630f98c`. The PSM `tin` and `tout` were both zero at that observation. Neither the fees nor vault availability are guaranteed to remain so. A funded Privy signing/receipt test is pending the owner's deferred dev sign-in.
