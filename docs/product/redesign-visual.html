Aura visual direction

Phase 3 of the redesign: the look, on top of the locked storyboards. Calm and exact like Mercury and Stripe. Neutral greys with one ultramarine accent, Geist with tabular numbers, balanced density, and soft corners, as picked by the owner on 29 September 2026. The design system (phase 4) holds the exact values. All data is fictional.

What's decided here

  • One accent, used only for the primary action, the current place in the navigation, and focus. Everything else is greys.
  • Green, red, and amber mean completed, failed, and needs attention. They're never decoration. Unavailable values are amber text, never a number.
  • Money uses tabular figures so columns line up. Addresses use the matching mono face.
  • Three corner sizes (6px controls, 8px inner blocks, 10px cards), hairline borders, and shadows only for things that float: sheets, popovers, and the menu button.
  • The wordmark is a placeholder: "aura" set in Geist with a simple ring. The final wordmark and app icon are designed later.
